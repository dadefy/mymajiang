# 内部联网测试指引

目标：**让同一个局域网里的人今天就能打开网址开始打牌**，不需要 Android 工具链、不需要打包 APK、不需要上架。

浏览器调试客户端复用 `apps/client` 里已经过单元测试的业务层（页面流转、断线重连、
令牌持有），所以它验过的行为与最终 LayaAir 版本一致 —— 区别只在渲染。

---

## 一、在一台机器上把服务端跑起来（这台就是"服务器"）

```powershell
cd <项目目录>
pnpm install                     # 首次
pnpm --filter @mianyang-mahjong/client build   # 调试客户端是编译产物，必须先构建
pnpm --filter @mianyang-mahjong/server build
```

然后在 `apps/server/.env` 里确认这几项：

```
HOST=0.0.0.0          # 让局域网内其它机器能连上
PUBLIC_HOST=192.168.x.x   # ← 改成这台机器在局域网里的 IP（下面讲怎么查）
ADMIN_ID=你的账号
ADMIN_PASSWORD=足够长的密码
```

> `HOST=0.0.0.0` 表示"监听所有网卡"。**但 `PUBLIC_HOST` 不能也写 0.0.0.0** ——
> 那是"本机所有网卡"的意思，不是别人能连的地址；写错了客户端的实时通道会连不上。

查本机局域网 IP：

```powershell
ipconfig | Select-String "IPv4"
```

启动：

```powershell
pnpm --filter @mianyang-mahjong/server start
```

看到这两行就是成功了：

```
[websocket] listening on 0.0.0.0:3001
[debug client] http://192.168.x.x:3000/debug
```

## 二、确认服务器自己对内可用

另开一个终端：

```powershell
pnpm --filter @mianyang-mahjong/server smoke
```

它会检查调试页能不能打开、脚本能不能加载、以及整条接口流程（登录 → 签发密钥 →
激活建号 → 发积分 → 建房）能不能走通。**全绿再叫人来测。**

## 三、给每个测试的人发两样东西

1. **网址**：`http://<你的局域网IP>:3000/debug`
2. **一把邀请密钥**：在 `http://<你的局域网IP>:3000/admin` 里签发
   （用 `ADMIN_ID` / `ADMIN_PASSWORD` 登录），或者用接口签发

## 四、⚠️ 每人建号后，你要给他们的账号发积分

**这是最容易卡住的一步**：扑克规则要求**至少 500 积分才能进房**，而新账号是 0 分，
所以**不发积分他们连房间都建不了**，只会看到一个 409 错误。

在管理后台 →「用户管理」→ 找到那个账号 →「积分」→ 填 `2000`，原因写"内测发放"。

## 五、开打

四个测试者各自在浏览器打开那个网址：

1. 输入各自的邀请密钥 → 第一次会要求填昵称 → 进主页
2. **一个人**点「建一个新房间」，把房间 ID 发给另外三个人
3. 另外三个人在主页的输入框里填房间 ID → 点「加入」
4. 四个人都点「我准备好了」，房主点「开始对局」
5. 按提示走：换三张 → 定缺 → 行牌（点手牌即出牌）

刷新页面不会掉线（令牌存在浏览器里，会自动恢复）。真掉线了会按 0.5/1/2/4/8 秒退避重连。

## 常见问题

| 现象 | 原因 |
| --- | --- |
| 别人打不开网址 | `HOST` 还是 `127.0.0.1`；或者 Windows 防火墙拦了 3000/3001 端口 |
| 能进主页但一直"断线" | `PUBLIC_HOST` 写成了 `0.0.0.0`，实时通道连错地址 |
| 建房报 409「至少 500 积分」 | 还没给这个账号发积分，见第四节 |
| 战绩是空的 | 内存模式（`DATABASE_URL` 为空）没有历史可查，这是设计如此；要留存战绩就配 PostgreSQL |
| 发了图片但看不到 | 内测阶段还没做客户端上传界面；服务端已就绪（见 PROJECT_STATUS 4.18） |
| 服务器重启后账号没了 | 内存模式重启丢数据。要让账号留下来就配 `DATABASE_URL` |

## 与最终 APK 的关系

| | 浏览器调试客户端 | LayaAir APK（`apps/apk`） |
| --- | --- | --- |
| 用途 | **内测**：打开网址就能玩 | 上线给玩家 |
| 业务层 | `apps/client`（共用） | `apps/client`（共用） |
| 传输层 | `apps/client/src/browser/transports.ts` | `apps/apk/src/laya-transports.ts` |
| 需要工具链 | 无 | LayaAir + Android 打包 |

两边共用同一套业务层，所以内测期间发现的行为问题，修一次两边都受益。
