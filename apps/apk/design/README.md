## v3 关键页设计说明

- **登录**：左 58% 品牌视觉（大字麻雀精灵 + 金线 + 麻将牌剪影 中發白🀙），右 42% 登录区；状态陈列在下方（登录中/失败/断网）。
- **大厅**：中央椭圆木边牌桌做主视觉，创建/加入做成**立在桌上的两张大麻将牌**（金面/象牙面），桌上散牌剪影；左上玩家信息无卡片；右上 图标+短文字 入口（战绩/群聊·未读/个人中心/设置）；品牌只在左上轻量出现。
- **加入房间**：房号格升级为**麻将牌质感**（象牙牌面+投影+当前位金框）；数字键盘 170×86 手游按键；未满 6 位确认禁用。
- **4 人等待**：**四人围桌布局**——中央木边牌桌（房号/玩法/局数/开始游戏[房主]），四座位环绕上/左/右/下；空位虚线；顶部返回大厅/退出房间；非房主视角换「等待房主开始」（不放假按钮）。
- **群聊主页**：v2 结构保留，字号按 v3 上调，气泡/成员栏更柔和。

## 品牌使用位置

麻雀精灵只出现在：登录页（大字）、大厅左上（轻量）。业务页面（创建/加入/等待/个人中心/战绩/设置/群聊/弹窗/网络/结束页）**不重复品牌名**，避免网页式统一标题栏。
